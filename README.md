### 📌 Projeto em destaque

**Orçamento Inteligente** — sistema completo pra orçamento de instalação de CFTV/segurança
eletrônica: canvas visual pra montar o equipamento, motor de sugestão de itens que faltam
(switch PoE, cabo, fonte, gravação), geocodificação de endereço com mapa interativo pra
planejar a instalação no local, e fluxo de aprovação por etapas (aberto → negociação →
fechado) com controle de acesso.

- Front-end em React + Vite, canvas interativo com React Flow
- Back-end em Node.js puro (sem framework), MongoDB
- Mapa com Leaflet/MapLibre, geocodificação via OpenStreetMap
- Autenticação por sessão com papéis de usuário (admin/usuário)
